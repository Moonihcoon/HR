# MoonHR 노무 대시보드

인사담당자를 위한 노동법 조문·처벌규정 대시보드입니다. **법제처 국가법령정보센터 Open API**에 연동되어 있어 조문 원문과 시행일을 실시간으로 불러옵니다.

🔗 https://moonhr-handbook.vercel.app

## 주요 기능
| 메뉴 | 내용 |
|---|---|
| 대시보드 | 핵심 지표, 다가오는 개정·시행 일정(D-day), 법령 최신 현황(법제처 자동 업데이트), 분야별 바로가기 |
| 조문 찾기 | 10개 분야 42개 주제 검색. 분야 필터, 5인 미만 적용 필터, 관련도·법령순·최근개정순 정렬. **모든 항목 하단에 위반 시 처벌규정 표기 → 클릭하면 법문 원문 표시** |
| 법령 전문·검색 | 주요 노동법령 10개 전문 열람, 조문 내 검색, 법제처 전체 법령 검색 |
| 실무 계산기 | 연차, 퇴직금, 주휴수당, 최저임금 충족 여부, 가산수당, 해고예고수당 |
| 법정 기한 | 금품청산·퇴직금 14일, 해고예고 30일 등 16개 기한 날짜 계산 |
| 개정·시행 일정 | 2026~2028년 주요 개정사항(임금체불 처벌 상향, 육아지원 확대, 성희롱 제재 확대 등) |
| API 설정 | 연동 상태 테스트, OC 직접 입력(선택), 캐시 비우기 |

## 법제처 API 연동
- 서버리스 함수 `api/law.js`가 `https://www.law.go.kr/DRF`(lawSearch.do / lawService.do)를 대신 호출합니다(CORS 우회, 인증키 보호).
- **인증키(OC)**: Vercel 환경변수 `LAW_OC`를 쓰고, 설정하지 않으면 코드에 넣어 둔 기본값을 씁니다.
- **자동 업데이트**: 응답을 Vercel CDN에 12시간 캐시한 뒤 백그라운드에서 다시 확인합니다(`stale-while-revalidate`). 법령이 개정되면 다시 배포하지 않아도 원문과 시행일이 바뀝니다.

| action | 예시 |
|---|---|
| `article` | `/api/law?action=article&law=근로기준법&jo=76&br=2` |
| `full` | `/api/law?action=full&law=최저임금법` |
| `search` | `/api/law?action=search&query=휴게&search=2` (본문검색) |
| `info` | `/api/law?action=info&laws=근로기준법,최저임금법` |

## 개발·테스트
```bash
npm run dev            # http://localhost:3000 (실제 법제처 API 호출)
MOCK=1 npm run dev     # 목업 응답으로 실행
npm test               # 데이터 무결성 · 계산기 · API 핸들러 테스트
```

## 데이터 기준
- 요약·처벌규정 기준일: 2026-11-13 (법제처 원문으로 벌칙 조항 대조 확인)

> 이 서비스의 요약과 계산 결과는 참고용이며 법적 효력이 없습니다. 원문은 [국가법령정보센터](https://www.law.go.kr)에서 확인하고, 구체적인 사안은 전문가와 상담하세요.
